# Claude Architectural Refactor Skill

A reasoning skill for Claude that prevents bad refactors 
before they start.

## What it does
Gives Claude a structured mental model for planning 
refactors — risk assessment first, phased execution, 
no big-bang rewrites.

## Who it's for
Developers using Claude in Cursor, Claude.ai projects, 
or any AI-assisted workflow. This is a protocol for AI-assisted solo development, not a team engineering standard.

## How to use it
Copy `SKILL.md` content into your Claude project 
instructions or paste it as context before any 
refactor conversation.

## Why it exists
Because AI will happily refactor your entire codebase 
at 2am if you let it. This makes it think first.
